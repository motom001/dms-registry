# Noto Sans

`code/daten/noto-sans.ttf`, `noto-sans-fett.ttf`, `noto-sans-kursiv.ttf` und `noto-sans-fettkursiv.ttf` sind die Dateien
`NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`, `NotoSans-Italic.ttf` und `NotoSans-BoldItalic.ttf` aus
`fonts/NotoSans/unhinted/ttf/` im Repository [notofonts/notofonts.github.io](https://github.com/notofonts/notofonts.github.io)
(Commit `86ce02c0fe7890f5936c5dffb26fca0797d1be64`), unverändert; `code/bauen.sh` holt sie und prüft ihre
SHA-256-Prüfsummen. Das Paket setzt damit E-Mails zu Seiten und bettet in die Archivfassung nur die benutzten Zeichen
ein (Teilmenge).
