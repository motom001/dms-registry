# Benachrichtigungen

Das Paket **Benachrichtigungen** bringt vorgefertigte [Automatisierungen](https://help.ablago.app/admin/aktuell/automatisierungen/) mit, die Ablago bisher fest eingebaut hatte. Du kannst sie unter **Werkbank → Ablage aufbauen → Automatisierungen** ansehen, anpassen und ein- oder ausschalten.

## Inhalt

| Automatisierung | Wenn | Dann |
| --- | --- | --- |
| Vertretung eingetragen | Abwesenheit gesetzt | Aufgabe an den Vertreter: „Hallo …, … hat dich vom … bis … als Vertreter hinterlegt.“ Sie erledigt sich, wenn die Abwesenheit endet oder sich die Vertretung ändert. |
| Vertretung zurückgezogen | Vertretung zurückgezogen (Abwesenheit beendet, anderer oder kein Vertreter mehr) | Benachrichtigung an den bisherigen Vertreter |

Beide sind nach der Installation **aus**. Beim Installieren fragt Ablago, welche gleich eingeschaltet werden sollen – vorausgewählt sind alle. Hat dein Ablago die Vertretungs-Aufgabe beim Update schon als eigene Automatisierung übernommen, ersetzt die mitgelieferte sie, solange du sie nicht geändert hast.

Weitere Automatisierungen (Tägliche Zusammenfassung, Favoriten, Aufgaben erinnern, Sammelmeldung Anmeldeschutz) kommen mit einer späteren Version.

## Voraussetzungen

- Ablago ab Version 0.177

## Rechte und Netz

Dieses Paket enthält keinen Code. Es legt nur Automatisierungen an; sie laufen mit dem Systemkonto „Automatisierung“.

# Notifications (English)

The **Notifications** package brings ready-made automations that Ablago used to have built in: **Substitute entered** (a task for the substitute, done when the absence ends) and **Substitution withdrawn** (a notification for the previous substitute). Both are off after installation; Ablago asks while installing which ones to switch on (all preselected). Requires Ablago 0.177 or later. No code, no network access.
