# Sprache: Französisch (Français)

Sprachpaket für Ablago ab 0.203.0: Ablago auf **Französisch**, in der vertrauten Anrede (tu).

> **Maschinell übersetzt – Verbesserungen willkommen.** Diese erste Fassung ist aus den englischen Texten von Ablago maschinell übersetzt. Einen falschen oder holprigen Text meldest du mit der Vorlage [„Übersetzung verbessern“](https://github.com/motom001/dms-registry/issues/new?template=uebersetzung.yml) – oder gleich als Pull Request. Wie das geht, steht im [Entwicklerhandbuch](https://help.ablago.app/entwickler/aktuell/pakete/#eine-sprache-beitragen).

## Was drin ist

- **Texte** (`texte/`): Anmeldung, Start von Ablago, Notfallzugang und die Spalten des Seitenrahmens.
- **Beschriftungen** (`beschriftungen/basis.yaml`): Mappentypen, Felder, Auswahlwerte und Ansichten des Pakets **Basis**.
- Alles andere erscheint auf **Englisch**, bis es übersetzt ist; Werkbank → Sprachen zeigt, wie viel schon übersetzt ist.
- Datum, Zahlen und Beträge nach den Regeln von `fr-FR`.

Nur Texte: kein Code, kein Zugriff auf Netzwerk und Internet, legt nichts in der Ablage an.

## Installieren

Werkbank → Pakete → Katalog → „Sprache: Französisch“ installieren, danach unter **Werkbank → Sprachen** erlauben. Jede Person wählt die Sprache dann in **Mein Konto**.
