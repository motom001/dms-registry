Beschreibung

ausführlich

Sprachpaket für Ablago ab 0.203.0: Ablago auf Türkisch, in der vertrauten Anrede (sen).

Maschinell übersetzt – Verbesserungen willkommen. Diese erste Fassung ist aus den englischen Texten von Ablago maschinell übersetzt. Einen falschen oder holprigen Text meldest du mit der Vorlage „Übersetzung verbessern“ – oder gleich als Pull Request. Wie das geht, steht im Entwicklerhandbuch.

Was drin ist

  • Texte (texte/): Anmeldung, Start von Ablago, Notfallzugang und die Spalten des Seitenrahmens.
  • Beschriftungen (beschriftungen/basis.yaml): Mappentypen, Felder, Auswahlwerte und Ansichten des Pakets Basis.
  • Alles andere erscheint auf Englisch, bis es übersetzt ist; Werkbank → Sprachen zeigt, wie viel schon übersetzt ist.
  • Datum, Zahlen und Beträge nach den Regeln von tr-TR.

Nur Texte: kein Code, kein Zugriff auf Netzwerk und Internet, legt nichts in der Ablage an.

Installieren

Werkbank → Pakete → Katalog → „Sprache: Türkisch“ installieren, danach unter Werkbank → Sprachen erlauben. Jede Person wählt die Sprache dann in Mein Konto.

English: Language package for Ablago 0.203.0 or later – Ablago in Türkçe. Machine-translated – improvements welcome: report a text with the “Improve a translation” issue template or send a pull request.
